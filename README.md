# Ludo Pro

A complete offline Ludo board game for Android, built with HTML5, CSS3, JavaScript and Capacitor.

**Developed by Sanaullah Khoso**

> **Build status:** the game, rules engine, AI and all tests were verified in a desktop browser (Chromium) and in Node.
> The Android APK itself **has not been built yet**, because the environment this project was written in had no access to
> the npm registry, Google Maven or Gradle. The GitHub Actions workflow in this repository builds it for you. See
> [Getting the APK](#getting-the-apk). Nothing below claims an APK exists until that workflow has run green.

## Features

- **Menus:** a big-tile dashboard (vs Computer, Local Play, Pass & Play, Power, Tokens), a "Continue Last Game" pill and a bottom bar (History / Rewards). Pick a **game mode**, then **players and colours** (2P / 3P / 4P; each colour card cycles Nobody / Computer / Human). Six-player boards are not supported (the engine has four colours).
- **Game modes:** Classic, **5 Minutes** (highest score when the clock ends), **Quick** (first to capture a token and bring one home), **Deathmatch** (first to 4 captures) and **Power** (magic spells plus board power-ups). A **Rules** popup (info button on each mode) explains every mode.
- **Power-up pads (Power mode):** nine pads on ordinary track squares - 🚀 Rocket (+8 steps), ⏫ Spring (+4), ×2 / ×3 Multiplier (the roll that landed there counts double / triple), 🛡️ Shield, 🧨 TNT (blasts unprotected tokens on and next to it, even your own), ❔ hidden Landmine (one use), 🧊 Ice (token frozen for its next turn) and 🔥 Fire (burns opponents on the next 3 squares, counts as a capture). Layout is random per game, saved with the game, and the computer understands them (it ignores the hidden mine). Original art, not copied from any other app.
- **Dice holders:** every player has a dice box with an avatar beside the board; the 3D dice flies from the holder of the current player to the middle of the board, tumbles, and flies back showing the number. The screen background takes the colour of the player whose turn it is.
- **12 token styles** (Pointy is the default, plus Chess, Coin, Gem, ...), all unlocked - no ads. Chosen on the Select Token screen and drawn as original vector art.
- **3D dice:** a smooth tumbling cube. Tap your dice holder to roll.
- **10 second turn timer:** a human who does not roll in time loses the turn; if no token is chosen in time a sensible move is played automatically. Configurable (Off / 10 / 15 / 20 s) in Settings.
- **Capture to open home:** a token cannot enter the home lane until its owner has captured an opponent token (it keeps circling the board, so the game can never get stuck). Can be switched off in Settings.
- **Magic Play spells** (cast before rolling, one of each at the start, a finished token earns another): 🎯 *Pick Dice* (choose your number), 🛡️ *Shield* (a token cannot be captured until your next turn), 💥 *Blast* (send an unprotected opponent token home; counts as a capture). The computer uses spells too. Magic can also be switched on for the offline modes.
- **Full classic Ludo rules:** four colours, four tokens each, six to leave the base, 52-cell shared track, safe squares (4 start cells + 4 stars), captures, private 5-cell home lanes, exact roll to finish, extra turns, three-sixes penalty, automatic skipping when no move is legal.
- **Configurable rules** (Settings): six to start, extra turn on six / capture / finishing, three sixes lose the turn, safe squares, exact finish.
- **AI:** Easy (random legal move), Medium (captures, finishing and progress first), Hard (scores every legal move for winning, captures, safety, danger and tempo). The AI only chooses among the moves the engine already marked legal, so it follows the same rules as a human.
- **Screens:** Splash, Dashboard, Select Game Mode, Player Selection, Ludo Board, Game Result, Settings, Game History, Player Profile, Rewards Dashboard.
- **Virtual coins:** welcome gift, daily login bonus with streak, free coins every 4 h, winning rewards, three daily missions, player level and XP, coin history.
- **Sound:** dice, token steps, captures, tokens home, win fanfare, button clicks and looping background music, all generated by `scripts/make_sounds.py`. Sound and music can be muted separately.
- **Storage:** coins, level, statistics, history, settings and the game in progress are saved in local storage (with a backup copy). The game autosaves after every move, when the app goes to the background and on Save & Exit. "Continue game" restores it.

### Coins have no value

Coins are virtual points for fun. There is **no gambling, no betting, no real-money deposits or withdrawals and no cash wagering**. Coins cannot be bought, sold or spent on chance. The economy module has no function for spending or withdrawing coins at all, and a test enforces that.

## Project structure

```
LudoPro/
  www/                      web app (Capacitor webDir)
    index.html
    css/style.css
    js/
      ludo-engine.js        ALL game rules (pure logic, no DOM)
      ludo-ai.js            Easy / Medium / Hard computer players
      ludo-board.js         board geometry + board renderer / token animation
      game-controller.js    turn flow, AI scheduling, animation order, autosave
      storage.js data.js economy.js audio.js app.js
    assets/{images,sounds,icons}
  android/                  generated by `npx cap add android` (see android/README.md)
  assets/                   source images for native icons + splash (@capacitor/assets)
  scripts/                  make_images.py, make_sounds.py, build-web.js, patch-android.js
  tests/                    engine.test.js, rules.test.js, app.test.js, timer.test.js, browser.test.js
  .github/workflows/build-apk.yml
  package.json  capacitor.config.json  README.md
```

Rules are never calculated in click handlers or animation code: the UI calls the controller, the controller calls the engine, and the engine decides.

### Engine position model

| value | meaning |
|---|---|
| `-1` | token in its home base |
| `0..50` | on the shared track (`0` = the colour's own start cell) |
| `51..55` | in the colour's private home lane |
| `56` | finished |

Absolute track cell = `(START_INDEX[seat] + position) % 52`, with starts at 0 / 13 / 26 / 39 (red, green, yellow, blue) and safe cells at 0, 8, 13, 21, 26, 34, 39, 47.

## Getting the APK

### Option A - GitHub Actions (recommended)

1. Create a GitHub repository and push this folder to it (branch `main`).
2. Open the **Actions** tab, choose **Build Android APK** and wait for it to finish (it also runs on every push and can be started manually with *Run workflow*).
3. Open the finished run and download the **LudoPro-debug-apk** artifact. Unzip it to get `LudoPro-debug.apk`.
4. Copy it to your phone and install it (allow "install unknown apps" for your file manager or browser).

The workflow installs Node 22 and JDK 21, installs dependencies, runs the tests, runs the web build check, creates the Android project with `npx cap add android` (if `android/gradlew` is not committed), generates icons and splash screens, runs `cap sync`, configures the Android SDK, builds with `./gradlew assembleDebug`, checks that the APK contains the game files, and uploads it.

If a step fails, the log tells you which. Typical first-run fixes: a Capacitor or Android Gradle Plugin version change (check the `@capacitor/*` versions in `package.json`) or the icon step (it is marked non-fatal and falls back to default icons).

### Option B - build on your own computer

Requirements: Node 20+, JDK 21, Android SDK (Android Studio installs it).

```bash
npm install
npm run build
npx cap add android
npm run assets
npm run android:sync
cd android && ./gradlew assembleDebug      # Windows: gradlew.bat assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

### Play in a browser (no Android needed)

```bash
npm run serve        # then open http://localhost:8080
```

## Regenerating artwork and sounds

```bash
python3 scripts/make_images.py     # needs Pillow + numpy; logo, icon, splash, background, coin
python3 scripts/make_sounds.py     # needs numpy + ffmpeg
```

- The debug APK is signed with the standard Android debug key. A Play Store release needs your own keystore and `./gradlew bundleRelease`.
- The hardware Back button opens the pause menu in a game, goes back one screen elsewhere, and asks before exiting from the dashboard.
- Package id: `com.sanaullahkhoso.ludopro`.
